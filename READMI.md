## 📖 Descripción

GhostNet Terminal es una aplicación web con estética cyberpunk inspirada en una terminal de red. El proyecto fue desarrollado como parte del curso **Desarrollador Web Front-End 1** de **KODIGO**, aplicando conceptos de estructura web, diseño responsivo y buenas prácticas de desarrollo.
